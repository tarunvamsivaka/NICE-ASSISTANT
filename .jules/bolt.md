## 2025-02-18 - Math loop micro-optimizations for JIT
**Learning:** For performance-critical math operations over large arrays (like vector cosine similarity), manual loop unrolling often degrades performance and harms readability. Instead, focus on clean micro-optimizations that modern JIT compilers (like V8) can exploit effectively: caching `.length` in a local variable, using local block-scoped variables for array indexing (e.g., `const ai = a[i]`), and combining `Math` function calls (e.g., `Math.sqrt(normA * normB)` instead of `Math.sqrt(normA) * Math.sqrt(normB)`). In benchmarks, these clean optimizations consistently outperformed the original naive loop by ~30% in V8 (Node v22).
**Action:** Always prefer these clean micro-optimizations over manual loop unrolling for math loops. Check array bounds and length caches, use local variables to avoid repeated property access, and algebraically simplify Math calls where possible.

## 2025-01-01 - Missing ARIA labels on Custom Toggles and Sliders
**Learning:** Custom UI controls like `.toggle-switch` (styled checkboxes) and range sliders within complex DOM structures (like a settings drawer) often lack built-in accessibility. Screen readers fail to associate the visually adjacent text labels (`.settings-name`) with the actual `input` elements when `aria-labelledby` or `aria-label` is not explicitly set, rendering them opaque to assistive technologies.
**Action:** Always add explicit `aria-label` attributes (or properly linked `aria-labelledby` IDs) directly on the `<input>` tags for custom form controls like toggles and sliders, especially when they are wrapped in styled container elements that decouple them from standard `<label>` text associations.
